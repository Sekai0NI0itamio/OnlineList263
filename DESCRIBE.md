# Online List — Modrinth draft

**Title:** Online List
**Description:** Lists all online players' names.
**Command:** `/onlinelist`

## Body

Lists all online players' names.

### Usage

`/onlinelist` — run in game chat (OP level 0 / everyone can use it).

### Installation

1. Install Forge 47.4.20 for Minecraft 1.20.1
2. Drop the jar into your `mods` folder
3. Type `/onlinelist` in chat
